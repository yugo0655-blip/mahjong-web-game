# 簡易麻雀ゲーム (mahjong-web-game)

`index.html` 単体で動作する、ブラウザ向けの簡易麻雀ゲームです。

## 主な機能
- 4人打ち（自分 + AI 3人）
- 牌をクリックして打牌、鳴き（ポン/チー/カン）や和了の選択が可能
- 「AI自動進行」による自動プレイ切り替え
- ゲーム内ガイド（基本 / 鳴き / 役・ルール / 操作）
- スマートフォン表示を意識したレスポンシブUI

## 遊び方
1. `index.html` をブラウザで開く
2. 「新規ゲーム」で対局を開始
3. 手牌の牌をクリックして打牌
4. 必要に応じて表示されるボタンで鳴き・和了を選択

## セットアップ
ビルドや依存関係のインストールは不要です。`index.html` をそのまま開いて遊べます。
